````markdown
## Getting Started

Follow the steps below to set up and run the portfolio locally.

### Prerequisites

Ensure you have a modern web browser like Chrome, Firefox, or Edge installed.

---

## Installation

### Downloading as ZIP

1. Navigate to the GitHub repository of this project: [https://github.com/adinathyadav2002/Portfolio](#).
2. Click the **"Code"** button.
3. Select **"Download ZIP"**.
4. Extract the downloaded ZIP file to a folder of your choice.
5. Open the `index.html` file in any web browser to view the portfolio.

### Cloning from GitHub

1. Make sure you have Git installed on your machine. [Download Git](https://git-scm.com/).
2. Open a terminal/command prompt.
3. Clone the repository using the command:
   ```bash
   git clone https://github.com/adinathyadav2002/Portfolio.git
   ```
````

4. Navigate to the project directory:
   ```bash
   cd portfolio
   ```
5. Open the `index.html` file in any web browser to view the portfolio.
